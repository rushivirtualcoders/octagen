# Liqui-Moly brand

## Hierarchy

1. Liqui-Moly = hero (product, motorsport, German engineering)
2. Octagen = trusted exclusive national distributor (header logo, footer statement)

Footer line to preserve:

> Liqui-Moly India is proudly operated and fulfilled by Octagen, the exclusive authorized national distributor.

## Visual

- Premium, sporty, mature. High-contrast dark racing imagery is acceptable in heroes.
- Trust markers: Made in Germany, F1 / MotoGP sponsor language only if CMS provides it.
- Flagship example in FRD: Top Tec 4200 with OEM Approved.

## UI bans

- Cart icon, sale ribbons, price chips
- Cluttered homepage search
- Playful/toy palettes that fight a motorsport brand

Rebuild in React + Vite. Do not restore the rejected Unsplash car-slideshow prototype.
