# Octagen × Liqui-Moly

Digital catalogue landing page for Liqui-Moly in India, operated by Octagen.

## Setup

```bash
cd web
npm install
npm run dev
```

Open http://localhost:3000

## Stack

React + TypeScript + Vite. CMS/admin is paused. No Next.js.
